# 块：错误处理原则（error-principles）

本块定义跨技能共用的错误处理不变量，无执行步骤，读取即生效，约束覆盖引用方任务全流程；跳过语义按 task-init 块通用机制执行。各技能的出口词汇定义与流程内错误分支留在技能正文，不入块。引用与编写约定见根 CLAUDE.md「跨技能协议块」节。

## 不变量

以下约束适用于全流程，不被任何分支覆盖：

- 认证、权限、网络和 hook 错误：显示原始错误和结果，不自动重试；
- 任何内部规则初始化、修复或写入失败：停止当前任务，不继续执行依赖该规则的动作；
- 远程状态无法证明可安全操作时停止远程写入，不自动执行 git pull、merge、rebase 或任何改写本地历史的操作。
